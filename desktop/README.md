# Ghost Hunter v5.1 for Windows (.exe)

Bat counter and ghost bat ID for trail-cam video and bat detector recordings. Everything runs on your own computer; nothing is uploaded.

## What's new in 5.1
- A pixel-art ghost bat flaps in the bottom-left corner, blended into the app background.
- `GhostHunter.exe` opens the app in its own window.
- The sound judge, video counter and everything else are the same as 5.0.

## Full desktop app (recommended)
1. Go to **[Releases → v5.1](https://github.com/shua1234/GHOSTHUNTER/releases/tag/v5.1)** and download **`Ghost-Hunter-v5.1-Windows.exe`** (about 98 MB).
2. Save it somewhere it will stay (for example Documents) and double-click it.
3. The first time, Windows may say "Windows protected your PC" because the exe isn't signed. Click **More info**, then **Run anyway**.
4. For a desktop icon, right-click the exe → **Send to → Desktop (create shortcut)**.

## Light version (opens the web app in its own window)
1. On this repo's main page, tap **Code → Download ZIP**, then unzip it somewhere it will stay (for example Documents).
2. Open the `desktop` folder and double-click **GhostHunter.exe**. It opens Ghost Hunter in its own window, using Edge or Chrome.
3. The first time, Windows may say "Windows protected your PC" because the exe isn't signed. Click **More info**, then **Run anyway**.
4. For a desktop icon, double-click **Make desktop icon (Windows).bat**, or right-click `GhostHunter.exe` → **Send to → Desktop (create shortcut)**.

Keep everything in the `desktop` folder together: the exe needs `Ghost Hunter v5.1.html` next to it.

## Mac or anything else
Open `Ghost Hunter v5.1.html` in any browser. It works offline.

For a Mac desktop icon: right-click the html file → **Make Alias** and drag the alias to your desktop. Open `ghost_hunter_icon.png` in Preview, choose **Edit → Select All** then **Edit → Copy**, select the alias, press **Cmd+I**, click the small icon at the top left and press **Cmd+V**.

# Ghost Hunter v5.1 for Windows (.exe)

The Ghost Hunter bat counter and ghost bat ID for your Windows PC. Everything stays on your computer; nothing is uploaded.

## Install on your PC
1. Download **`Ghost-Hunter-v5.1-Windows.exe`** from **[Releases → v5.1](https://github.com/shua1234/GHOSTHUNTER/releases/tag/v5.1)**.
2. Move it somewhere it will stay, such as Documents, and double-click it.
3. If Windows says "Windows protected your PC", click **More info → Run anyway**. This happens because the app isn't from the Microsoft Store.
4. For a desktop icon, right-click the exe → **Send to → Desktop (create shortcut)**.

Looking for the phone version? See [`mobile/README.md`](../mobile/README.md).
